# Brandrails logo

The Brandrails mark is built on the Holisy Design logo's rules: the Holisy "i" (dot and stem) grows into a "b".

- Stem 61.2 wide with round caps (radius 30.6), dot radius 30.33: the same as the Holisy mark.
- Rails 56.06 thick measured vertically, at 9.57°: the same as the Holisy body band. The upper rail sits where the Holisy band does.
- Box 283.32 × 515.51, the Holisy size, so both marks share one grid.
- One colour, `#212121`. Use the inverted files on dark backgrounds. Don't recolour, stretch or add effects.

| File | Use |
|---|---|
| `brandrails-logo.svg` / `.png` | Default mark (PNG 1024 px tall, transparent) |
| `brandrails-logo-inverted.svg` / `.png` | White mark for dark backgrounds |
| `brandrails-mark-square.svg`, `brandrails-mark-512.png` | Square, unpadded: favicons, app icons |
| `brandrails-avatar.png` | 1000 × 1000 on white with padding: GitHub org, social avatars |

The site favicon (`public/favicon.svg`) switches to white in dark mode.
