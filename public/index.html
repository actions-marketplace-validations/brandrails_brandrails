Keep AI agents on your design system

Brandrails turns the design decisions already in your code into one tokens.json, writes design rules for every AI tool your team uses, and flags hard-coded colours and spacing before they reach main.

Add it to your agent See the code

How it works

1

Read

Pulls tokens from Tailwind @theme, CSS variables, shadcn/ui themes, SCSS and Angular Material into one DTCG file.

2

Generate

Writes rules for AGENTS.md, Claude Code, Cursor, Copilot and Figma Make, small enough not to eat the context window.

3

Check

Finds #3b82f6 and p-[13px] in new code and names the token to use instead.
